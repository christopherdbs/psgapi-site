# PSGAPI Site : psgapi.com

Welcome to the codebase of the [PSGAPI](https://psgapi.com) site, a user interface built with Vite and React.

## Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/christopherdbs/psgapi-site.git
cd psgapi-site
npm install
```

## Development

To start the development server, run:

```bash
npm run dev
```

The site will be accessible at http://localhost:5173.
